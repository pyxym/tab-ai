# ⚡ TabQuest 성능 최적화 요약 (쉬운 설명)

> 💡 **한 줄 요약**: 우리 확장 프로그램이 데이터를 너무 자주 저장해서 느려지고 배터리를 많이 먹어요. 이걸 고치면 훨씬 빨라집니다!

## 🤔 지금 무슨 문제가 있나요?

### 문제 1: 💾 저장을 너무 자주 해요

**일상 비유로 설명하면**:
```
지금 상황 😰
- 메모장에 글자 한 개 쓸 때마다 저장 버튼 누르기
- 하루에 10,000번 저장!
- → 컴퓨터가 계속 바쁨, 배터리 빨리 닳음

개선 후 😊
- 문단 하나 끝나면 한 번만 저장
- 하루에 1,000번만 저장
- → 컴퓨터 여유로움, 배터리 오래감
```

**실제로는**:
- 탭을 바꿀 때마다 데이터를 저장해요
- 1분마다 또 저장해요
- 하루에 5,000~10,000번 저장 😱

**이게 왜 문제인가요?**
- 📱 배터리가 빨리 닳아요
- 🐌 브라우저가 느려져요
- 🔥 노트북이 뜨거워져요

### 문제 2: 🔄 같은 계산을 계속 반복해요

**일상 비유로 설명하면**:
```
지금 상황 😰
- 엄마 전화번호를 볼 때마다 전화번호부 찾아보기
- 아빠 전화번호를 볼 때마다 또 전화번호부 찾아보기
- 매번 찾느라 시간 낭비!

개선 후 😊
- 한 번 본 전화번호는 머릿속에 기억
- 다음부터는 바로 떠올림
- 시간 절약!
```

**실제로는**:
- 탭의 카테고리를 매번 계산해요 (이게 업무용 탭인지, 유튜브 탭인지)
- 한 번 계산했어도 다음에 또 계산해요
- 계산하는데 시간이 걸려요

### 문제 3: ⚠️ 잘못된 시계를 사용해요

**일상 비유로 설명하면**:
```
지금 상황 😰
- 손목시계 타이머로 알람 맞춰놓기
- 시계가 꺼지면 알람도 멈춤
- → 알람이 안 울림!

개선 후 😊
- 스마트폰 알람 사용
- 폰이 꺼져도 알람은 울림
- → 제대로 작동!
```

**실제로는**:
- 오래된 타이머 방식(`setInterval`) 사용
- 브라우저가 확장 프로그램을 끄면 타이머도 멈춤
- 데이터 정리가 제대로 안 됨

## 🎯 어떻게 고치나요?

### 방법 1: 설정만 바꾸기 (제일 쉬움! 10분 소요)

**이렇게 바꾸면 돼요**:

```typescript
// 파일: src/utils/configs.ts

// 옛날 설정 ❌
MIN_ACTIVE_TIME: 30000,        // 30초
DEBOUNCE_DELAY: 3000,          // 3초
ALARM_PERIOD_MINUTES: 1,       // 1분
CLEANUP_DAYS: 30,              // 30일

// 새로운 설정 ✅
MIN_ACTIVE_TIME: 60000,        // 60초 (2배)
DEBOUNCE_DELAY: 10000,         // 10초 (3배)
ALARM_PERIOD_MINUTES: 5,       // 5분 (5배)
CLEANUP_DAYS: 14,              // 14일 (절반)
```

**이게 뭘 의미하나요?**
- `MIN_ACTIVE_TIME`: "30초 이상 본 탭만 기록해" → "60초 이상 본 탭만 기록해"
- `DEBOUNCE_DELAY`: "3초마다 저장해" → "10초마다 저장해"
- `ALARM_PERIOD_MINUTES`: "1분마다 체크해" → "5분마다 체크해"
- `CLEANUP_DAYS`: "30일 된 데이터 지워" → "14일 된 데이터 지워"

**효과**:
- ✅ 저장 횟수 70% 감소
- ✅ 배터리 50% 절약
- ✅ 데이터 용량 50% 절약

### 방법 2: 시계 고치기 (쉬움! 5분 소요)

**이렇게 바꾸면 돼요**:

```typescript
// 파일: src/entrypoints/background.ts

// 옛날 방식 ❌
setInterval(() => {
  TabTracker.cleanupOldData();
}, 24 * 60 * 60 * 1000);

// 새로운 방식 ✅
chrome.alarms.create('dailyCleanup', {
  periodInMinutes: 24 * 60  // 24시간
});

chrome.alarms.onAlarm.addListener((alarm) => {
  if (alarm.name === 'dailyCleanup') {
    TabTracker.cleanupOldData();
  }
});
```

**이게 뭘 의미하나요?**
- 브라우저가 제공하는 제대로 된 알람 기능 사용
- 확장 프로그램이 꺼져도 알람은 작동
- 데이터 정리가 확실하게 실행됨

### 방법 3: 저장 방식 개선하기 (조금 어려움, 1-2시간 소요)

**개념**:
```
옛날 방식 ❌
탭 바꿈 → 바로 저장
탭 바꿈 → 바로 저장
탭 바꿈 → 바로 저장
(너무 자주 저장!)

새로운 방식 ✅
탭 바꿈 → 메모리에 기록
탭 바꿈 → 메모리에 기록
탭 바꿈 → 메모리에 기록
30초 경과 → 한 번에 저장!
(모아서 저장!)
```

**이게 뭘 의미하나요?**
- 변경사항을 메모리에 모아둠
- 30초마다 한 번씩만 실제로 저장
- 저장 횟수가 90% 줄어듦!

## 📝 용어 설명

혹시 어려운 단어가 있었다면:

- **스토리지**: 데이터를 저장하는 곳 (USB 메모리 같은 것)
- **메모리**: 임시로 기억하는 곳 (작업 중인 내용)
- **캐싱**: 한 번 계산한 결과를 기억해두는 것
- **배치 쓰기**: 여러 개를 모아서 한 번에 저장하는 것
- **Service Worker**: 브라우저가 백그라운드에서 돌리는 프로그램
- **알람**: 정해진 시간에 실행되는 타이머
