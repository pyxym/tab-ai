## 🚀 Quick Start

TabQuest is a Chrome extension built with WXT framework that helps users manage browser tabs intelligently.

### Key Features
- 🎯 **Smart Tab Organization**: Category-based automatic grouping
- 📊 **Usage Tracking**: Real-time tab monitoring
- 🏷️ **Category Management**: Custom category system
- 🤖 **AI Insights**: Smart productivity suggestions
- 🌍 **Multi-language**: English, Korean, Japanese

### Project Structure
```
tab-quest/
├── docs/              # 📚 Documentation
├── src/
│   ├── entrypoints/   # Entry points (popup, background, options)
│   ├── components/    # React components
│   │   ├── charts/    # Chart components
│   │   ├── modals/    # Modal dialogs
│   │   ├── pages/     # Page components
│   │   ├── shared/    # Shared components
│   │   └── ui/        # UI primitives
│   ├── store/         # Zustand stores
│   ├── utils/         # Utility functions
│   ├── lib/           # Core libraries
│   ├── locales/       # i18n translations
│   └── types/         # TypeScript types
└── public/            # Static assets
```
